Entrar no painel

O painel salva os vinhos direto no GitHub, onde o site está publicado. Para isso ele precisa de uma chave de acesso sua.

Chave de acesso do GitHub

  1. Abra github.com/settings/personal-access-tokens/new com a sua conta.
  2. Em Token name escreva "Painel Malbê" e em Expiration escolha 1 ano.
  3. Em Repository access escolha Only select repositories e marque malbe-site.
  4. Em Permissions → Repository permissions → Contents escolha Read and write.
  5. Clique em Generate token, copie a chave e cole abaixo.

A chave fica guardada só neste navegador. Em outro aparelho, você cola de novo.
